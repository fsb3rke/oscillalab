# OscillaLab

Klasik mekanik ve salinim sistemleri icin RK4, Three.js, OLS regresyon ve LaTeX rapor destekli fizik laboratuvari uygulamasi.

## Modul Durumu
- EXP-01: torsional-pendulum
- EXP-02: driven-spring-mass
- EXP-03: coupled-oscillators
- EXP-04: damped-driven-pendulum (planlanan)

## Komutlar
- `npm run dev`
- `npm test`
- `npm run build`
